# 早班中班Checklist

每日離峰檢查打勾，加上物料盤點（自動對照前一天庫存、一鍵複製到群組）。資料存在 Google 試算表。

## 設定試算表（只要做一次）

1. 新建一份 Google 試算表，選單「擴充功能 → Apps Script」。
2. 把 `apps-script/Code.gs` 的內容整份貼上，存檔。
3. 上方函式選單選 `setup`，按「執行」，依提示授權。試算表會出現「資料」、「盤點紀錄」、「修改紀錄」三個工作表，並存入 261011 的盤點。
4. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
5. 複製網頁應用程式網址（`https://script.google.com/macros/s/.../exec`），貼到 `index.html` 裡的 `const API_URL=""`。

之後改了 `Code.gs`，要用「部署 → 管理部署作業 → 編輯 → 版本選新版本」更新，網址不變。

## 填錯怎麼辦

- 當天填錯：直接改數字，會覆蓋原本的。
- 隔天才發現：網頁上方日期切回那一天再改。
- 想查原本填了什麼：看試算表的「修改紀錄」工作表，每次儲存都有一筆。
